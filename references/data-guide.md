# 数据填充指南（data-guide）

本 skill 的产物是一个**逐句讲解的日语歌词学习网页**。模板 `assets/lyric-page-template.html` 已包含全部样式、交互与渲染逻辑，你只需要向其中填入两块数据：`const S=[...]`（歌词数据）和 `const POS={...}`（词性与活用表）。

流程总览：
1. 用搜索检索用户指定歌曲的**官方歌词**（日文原文）。
2. 把歌词原样发给用户，**请其确认是这首歌**。确认后再进入填数据；用户说不是则重新检索。
3. 逐句切分、标注、填入 `S` 与 `POS`，用模板生成网页。

## 一、S 数组（每句歌词）

`S` 是一个数组，一个元素代表**一句歌词**。结构：

```js
{
  jp:  '<ruby>私<rt>わたし</rt></ruby>に<ruby>蠢<rt>うごめ</rt></ruby>く<ruby>獣<rt>けもの</rt></ruby>',
  seg: '私｜に｜蠢く｜獣',        // 分词，用全角「｜」分隔
  tr:  '在我体内躁动的野兽',       // 中文翻译
  gram:'<code>Ｖ＋名词</code>：动词简体直接修饰名词。',  // 语法说明（可含 <code>）
  ws:  [ /* 本句出现的每个词的数组 */ ]
}
```

`ws` 里每个词是一个 5 元素数组：`[词形, 读音, 释义, 等级, 说明]`

| 位置 | 含义 | 示例 | 说明 |
|---|---|---|---|
| 0 | 词形（词典形） | `'蠢く'` | 活用时填**原形**，如「浮かんで」填 `'浮かぶ'` |
| 1 | 读音（振假名） | `'うごめく'` | 汉字/片假名词必填；**纯平假名词留空 `''`** |
| 2 | 中文释义 | `'蠢动、躁动'` | |
| 3 | JLPT 等级 | `'n3'` | 只能是 `n5`/`n4`/`n3`/`n2` |
| 4 | 说明（可空） | `'て形：浮かんで'` | 只写**补充信息**；若与词性/形态重复，则留空 `''` |

等级参考：N5 常用基础词（我、水、手、火、云、梦、没有、悲伤…）；N4 常见中阶（水面、消失、想象、握、数…）；N3 中高阶/惯用（蠢动、泡沫、遥、灵魂、掬…）；N2 生僻/成语/外来语（半信半疑、满身疮痍…）。

### JLPT 分级 Rubric（填 `ws` 第 3 列等级时对照）

判定顺序从上到下，命中即停；拿不准往低标半级。

| 级别 | 判定特征 | 示例 |
|---|---|---|
| **n5** | ① 语法功能词（助词/助动词/基础副词）<br>② 小学级日常名词、代词（私・海・足・目・今・鳥・靴）<br>③ 最基础动词（する・ある・見る・なる・乗る・脱ぐ） | 僕、貴方、海、足、今、が/は/を/に/へ、まだ、もう |
| **n4** | ① 初级教材（大家的日语初级/标准日本语初级）出现的常见词<br>② 日常生活/新闻高频名词动词<br>③ **常见**外来语（ライオン・アフリカ・カメラ・テレビ）<br>④ 常见イ/ナ形容词 | 遠く、身体、音、息、越える、吸う、鳴く、引く、柔らかい |
| **n3** | ① 中级教材（新完全掌握中级等）出现<br>② 抽象名词、书面词<br>③ 复合动词、惯用短语（尾动词是 N5 但整个词日常不用时升一级）<br>④ 中阶副词（ついに・ようやく・ずっと・そっと）<br>⑤ 句型（という・みたいに・まま・だけに） | 想像力、重力、縛り、潮風、立ち上がる、歩き出す、気になる、気が付く、ただの |
| **n2** | ① 文学/书面语动词<br>② 生僻或诗意名词<br>③ **生僻**外来语、四字熟语<br>④ 母语者日常也少用的词 | 戯れる、しゃがみ込む、脱ぎ去る、跳ね遊ぶ、木漏れ日、さざなみ |

**三条校准规则：**

1. **拿不准往低标半级。** 标成 n4 但其实认识，无损失；标成 n2 误以为是生词，反而吓退初学者。
2. **外来语按"外国人在日本街头能不能一眼懂"判**，不按片假名字数判：ライオン/アフリカ → n4；`エトランゼ`/`シニフィエ` → n2。
3. **复合动词看尾动词 + 整体常见度**：尾动词是 n5，但整个词日常不用就升一级。如`脱ぎ去る`比`脱ぐ`文学 → n2；`歩き出す`中级常见 → n3。

**诚实上限：** 歌词文学用法大量不在 JLPT 考纲内，分级只作"学习优先级提示"，不代表考试大纲。真要 100% 准需逐词对照 JLPT 官方词汇表。

读音规则（重要）：
- 纯平假名词（如 `に`、`あぶく`、`どうして`）→ 读音留 `''`（浮层不显示读音行）。
- 片假名词 → 读音填**平假名**（如 `トートロジー` → `'とーとろじー'`）。
- 汉字词 → 读音填假名（`'私'` → `'わたし'`）。

说明去重规则：说明里如果只是重复形态（`て形：…`、`た形：…`、`命令形：…`、`名词`、`副词` 等已在词性/形态行出现的内容），一律留空。

## 二、POS 表（词性与活用）

`POS` 是一个对象，**按词形（词典形）索引**，为每个词提供词性，为四类词提供形态。**同一词形只写一次**（重复出现会自动标注出处）。

结构：

```js
const POS={
  '词形': { pos:'词性', form:'当前形态', base:'原形', forms:[['形态名','词形'],...] }
};
```

字段：
- `pos`（必填）：词性。取值见下方列表。
- `form`（仅 动词/形容词/助动词/句型 需要）：该词当前出现的形态。
- `base`（仅活用变体需要）：原形，如 `'浮かぶ'` 的 base 是 `'浮かぶ'`。
- `forms`（仅 动词/形容词/助动词/句型 需要）：该词**完整**形态清单，每项 `[形态名, 词形]`，**包含当前形态**。浮层会自动剔除当前形态、显示其余为「其他形态」。

### 词性取值

`名词`、`代词`、`数词`、`动词`、`动词短语`、`动词（敬语）`、`动词（使役形）`、`イ形容词`、`ナ形容词`、`助词`、`助动词`、`句型`、`惯用短语`、`副词`、`接续词`、`拟声词`、`外来语·名词`、`名词（サ变）`、`名词（四字成语）`。

### 形态名（form 与 forms 中使用的名称）

- 动词：`原形`、`て形`、`た形`、`ない形`、`假定形`、`命令形`、`意向形`、`～たい形`、`使役形`
- イ形容词：`原形`、`连用形（く）`、`过去形（かった）`、`假定形（ければ）`、`样态（そう）`
- ナ形容词：`原形`、`连体形（な）`、`连用形（に）`、`终止形（だ）`
- 助动词/句型：按其接续形态命名（如 `～たい形`、`～て形`、`许可`）

### POS 表示例（真实片段，来自《あぶく》）

```js
const POS={
  // 名词类（只需 pos，无 form）
  '私':{pos:'代词',form:'原形'},
  '獣':{pos:'名词',form:'原形'},
  'あぶく':{pos:'名词',form:'原形'},
  // 动词原形（列完整形态）
  '蠢く':{pos:'动词',form:'原形（连体修饰）',forms:[['て形','蠢いて'],['た形','蠢いた'],['ない形','蠢かない'],['假定形','蠢けば'],['命令形','蠢け'],['意向形','蠢こう']]},
  // 动词活用形（变体：给 base，forms 含全部形态）
  '浮かぶ':{pos:'动词',form:'て形',base:'浮かぶ',forms:[['て形','浮かんで'],['た形','浮かんだ'],['ない形','浮かばない'],['假定形','浮かべば'],['命令形','浮かべ'],['意向形','浮かぼう']]},
  // 形容词
  '悲しい':{pos:'イ形容词',form:'原形',forms:[['连用形','悲しく'],['过去形','悲しかった'],['假定形','悲しければ'],['样态','悲しそう']]},
  '滑稽':{pos:'ナ形容词',form:'连体形（な）',forms:[['连体形','滑稽な'],['连用形','滑稽に'],['终止形','滑稽だ'],['て形','滑稽で']]},
  // 助词（只需 pos）
  'に':{pos:'助词',form:'原形'},
  // 助动词 / 句型
  '～たい':{pos:'助动词',form:'～たい形',forms:[['终止形','～たい'],['连用形','～たく'],['过去形','～たかった'],['假定形','～たければ']]},
  '～でもいい':{pos:'句型（许可）',form:'原形',forms:[['许可','～てもいい'],['过去','～てもよかった'],['否定','～なくてもいい']]}
};
```

## 三、生成与交付

1. 复制 `assets/lyric-page-template.html` 到输出位置，改名为 `歌词名-歌词学习.html`（语义化）。
2. 把填好的 `S` 和 `POS` 替换进模板中对应占位（搜索 `TODO: 填充歌词数据` 与 `TODO: 填充词性与活用`）。
3. **替换 hero 元信息**（模板里 5 处占位符）：`[歌名]`（含 `<title>`、`<h1>`、页脚）、`[歌手名]`、`[歌名中文译名]`、`[作词人]`、`[一句歌词主题/简介]`。务必全部替换，否则会残留上一首的标题信息。
4. **设计 hero 氛围（配色 + 特效）**：每首歌按歌词意象定制 hero，模板默认是"深夜→破晓微光 + 飘雪"。改两处：① `.hero{}` 段的背景渐变（模板里带 `hero 氛围：配色 + 特效` 注释）——冷/暖色调、渐变走向随歌定；② 头部动画特效段（`.snow`，类名、HTML 子元素、`@keyframes` 命名一起换，可选泡沫上升 / 飘雪 / 花瓣飘落 / 星光闪烁 / 光尘漂浮 / 水面涟漪）。两处必须与这首歌的情绪一致，不要沿用上一首。
5. 用渲染工具自检（如 `html` skill 的 `scripts/shot.py`）确认无 JS 报错、桌面+移动端布局正常、hero 显示本首歌信息，再交付。
6. 用 `present_files` 交付 HTML。

## 四、质检要点

- `S` 里所有 `ws` 的词形，都必须在 `POS` 表中有键（缺失时该词浮层信息不全）。
- 四类词（动词/形容词/助动词/句型）必须给 `form` 和 `forms`；其它词只给 `pos` 即可。
- 纯平假名词读音留空；片假名词读音用平假名。
- 翻译要与原文逐句对应，语法说明面向日语学习者，用 `<code>` 标出关键句型。
