# 数据填充指南（data-guide）

本 skill 的产物是一个**逐句讲解的日语歌词学习网页**（HTML + CSS + JS + 数据，同目录四件套）。样式在 `lyric-page.css`，交互在 `lyric-page.js`，你只需要向 `assets/lyric-data.js` 填入两块数据：`export const S=[...]`（歌词数据）和 `export const POS={...}`（词性与活用表）。

流程总览：
1. 用搜索检索用户指定歌曲的**官方歌词**（日文原文）。
2. 把歌词原样发给用户，**请其确认是这首歌**。确认后再进入填数据；用户说不是则重新检索。
3. 逐句切分、标注、填入 `S` 与 `POS`，用模板生成网页。

---

## 一、S 数组（每句歌词）

`S` 是一个数组，一个元素代表**一句歌词**。结构（在 `lyric-data.js` 中写成 `export const S=[...]`）：

```js
{
  jp:  '<ruby>私<rt>わたし</rt></ruby>に<ruby>蠢<rt>うごめ</rt></ruby>く<ruby>獣<rt>けもの</rt></ruby>',
  seg: '私｜に｜蠢く｜獣',        // 分词，用全角「｜」分隔
  tr:  '在我体内躁动的野兽',       // 中文翻译
  gram:'<code>Ｖ＋名词</code>：动词简体直接修饰名词。',  // 语法说明（可含 <code>）
  ws:  [ /* 本句出现的每个词的数组 */ ]
}
```

### 英语跳过（硬性）

歌词中的**拉丁字母英文**（`A–Z` / `a–z`，如 `love`、`OK`、`yeah`、`Baby`）**一律不做处理**：

- `jp`：原样写入，不加 `<ruby>`
- `seg`：可整段保留为一段（或与邻近日语用 `｜` 隔开），**不要**把英文拆成生词
- `ws` / `POS`：**禁止**收录英文词
- `gram`：不要针对英文词做词法/语法讲解
- `tr`：整句可给中文大意；不要逐词翻译英文

**不算英语、仍按日语处理**：片假名外来语（`ライオン`、`カメラ`）、罗马字日语专名若需注音再另议——默认英文拉丁词跳过即可。

`ws` 里每个词是一个 5 元素数组：`[词形, 读音, 释义, 等级, 说明]`（仅日语词）

| 位置 | 含义 | 示例 | 说明 |
|---|---|---|---|
| 0 | 词形（字典形） | `'蠢く'` | 活用时填**字典形**，如「浮かんで」填 `'浮かぶ'` |
| 1 | 读音（振假名） | `'うごめく'` | 汉字/片假名词必填；**纯平假名词留空 `''`** |
| 2 | 中文释义 | `'蠢动、躁动'` | |
| 3 | JLPT 等级 | `'n3'` 或 `''` | **只**填 `references/jlpt/vocabulary.jsonl` 命中的 `lv`（`n5`/`n4`/`n3`/`n2`/`n1`）；索引无此词则填 `''`，禁止估级 |
| 4 | 说明（可空） | `''` | 只写**补充信息**；若与词性/形态重复（如 `て形：…`），则留空 `''` |

### JLPT 分级（唯一来源：vocabulary.jsonl / grammar.jsonl）

填 `ws` 第 3 列用词汇索引；`gram` 里若要标注语法等级用语法索引：

1. **不要整文件读入**。冒号后有空格。**先收集本首歌全部待定级词形，对词汇索引尽量一次查完**（词多可拆成每批 30–50 个），禁止一词一搜：
   ```bash
   grep -E '"k": "(会う|私|向こう|浮かぶ)"' references/jlpt/vocabulary.jsonl
   grep -E '"k": "(だに|〜から|だけ)"' references/jlpt/grammar.jsonl
   ```
2. 命中行的 `lv` 即等级。优先按**词形**查；若命中读音行（有 `"w"`），选 `w` 与当前词形一致的那条。
3. 命中行的 `m` 与歌词用法明显不符时，视为未命中。
4. **无命中 → 不分级**：`ws[3]=''`；`gram` 也不写「N3」等标签。禁止用语感补级。

两个索引由 `references/jlpt/build_index.py` 从各级 `vocabulary.md` / `grammar.md` 生成。

读音规则（重要）：
- 纯平假名词（如 `に`、`あぶく`、`どうして`）→ 读音留 `''`（浮层不显示读音行）。
- 片假名词 → 读音填**平假名**（如 `トートロジー` → `'とーとろじー'`）。
- 汉字词 → 读音填假名（`'私'` → `'わたし'`）。

说明去重规则：说明里如果只是重复形态（`て形：…`、`た形：…`、`命令形：…`、`名词`、`副词` 等已在词性/形态行出现的内容），一律留空。

### S 数组示例（真实片段，来自《あぶく》）

等级已按 `vocabulary.jsonl` 查过：有命中的写 `lv`，无命中（如「蠢く」「あぶく」）写 `''`。

## 二、POS 表（词性与活用）

`POS` 是一个对象，**按词形（字典形）索引**，为每个词提供词性，为四类词提供形态。**同一词形只写一次**（重复出现会自动标注出处）。

结构：

```js
const POS={
  '词形': { pos:'词性', form:'当前形态', base:'字典形', forms:[['形态名','词形'],...] }
};
```

字段：
- `pos`（必填）：词性。取值见下方列表。
- `form`（仅 动词/形容词/助动词/句型 需要）：该词当前出现的形态。
- `base`（仅活用变体需要）：字典形，如歌词里是「浮かんで」时，键与 `base` 都是 `'浮かぶ'`。
- `forms`（仅 动词/形容词/助动词/句型 需要）：该词**完整**形态清单，每项 `[形态名, 词形]`，**包含当前形态**。浮层会自动剔除当前形态、显示其余为「其他形态」。

### 词性取值

`名词`、`代词`、`数词`、`动词`、`动词短语`、`动词（敬语）`、`动词（使役态）`、`イ形容词`、`ナ形容词`、`助词`、`助动词`、`句型`、`惯用短语`、`副词`、`接续词`、`拟声词`、`外来语·名词`、`名词（サ变）`、`名词（四字成语）`。

### 形态名（form 与 forms 中使用的名称）

- **动词**（`form` / `forms` 必须用下列名称；`forms` 尽量列全 12 项）：
  `字典形`、`ない形`、`ます形`、`て形`、`た形`、`ば形`、`意志形`、`命令形`、`可能态`、`被动态`、`使役态`、`使役被动态`
- **形容词**（イ/ナ共用下列名称；`forms` 列全 6 项）：
  `字典形`、`否定形`、`过去形`、`て形`、`副词化`、`假定形`
- 助动词/句型：按其接续形态命名（如 `～たい形`、`～て形`、`许可`）

### POS 表示例（真实片段，来自《あぶく》）

```js
const POS={
  // 名词类（只需 pos）
  '私':{pos:'代词'},
  '獣':{pos:'名词'},
  'あぶく':{pos:'名词'},
  // 动词字典形（forms 列全 12 项）
  '蠢く':{pos:'动词',form:'字典形',forms:[
    ['字典形','蠢く'],['ない形','蠢かない'],['ます形','蠢きます'],['て形','蠢いて'],['た形','蠢いた'],
    ['ば形','蠢けば'],['意志形','蠢こう'],['命令形','蠢け'],
    ['可能态','蠢ける'],['被动态','蠢かれる'],['使役态','蠢かせる'],['使役被动态','蠢かせられる']
  ]},
  // 动词活用形（变体：给 base，forms 含全部形态）
  '浮かぶ':{pos:'动词',form:'て形',base:'浮かぶ',forms:[
    ['字典形','浮かぶ'],['ない形','浮かばない'],['ます形','浮かびます'],['て形','浮かんで'],['た形','浮かんだ'],
    ['ば形','浮かべば'],['意志形','浮かぼう'],['命令形','浮かべ'],
    ['可能态','浮かべる'],['被动态','浮かばれる'],['使役态','浮かばせる'],['使役被动态','浮かばせられる']
  ]},
  // 形容词（forms 列全 6 项：字典形/否定形/过去形/て形/副词化/假定形）
  '悲しい':{pos:'イ形容词',form:'字典形',forms:[
    ['字典形','悲しい'],['否定形','悲しくない'],['过去形','悲しかった'],
    ['て形','悲しくて'],['副词化','悲しく'],['假定形','悲しければ']
  ]},
  '滑稽':{pos:'ナ形容词',form:'字典形',forms:[
    ['字典形','滑稽'],['否定形','滑稽ではない'],['过去形','滑稽だった'],
    ['て形','滑稽で'],['副词化','滑稽に'],['假定形','滑稽なら']
  ]},
  // 助词（只需 pos）
  'に':{pos:'助词'},
  // 助动词 / 句型
  '～たい':{pos:'助动词',form:'～たい形',forms:[['终止形','～たい'],['连用形','～たく'],['过去形','～たかった'],['假定形','～たければ']]},
  '～でもいい':{pos:'句型（许可）',form:'原形',forms:[['许可','～てもいい'],['过去','～てもよかった'],['否定','～なくてもいい']]}
};
```

## 三、生成与交付

1. 把 `assets/` 四件套复制到同一输出目录：`lyric-page-template.html`（改名 `歌词名-歌词学习.html`）、`lyric-page.css`、`lyric-page.js`、`lyric-data.js`。
2. 把填好的 `S` 和 `POS` 写入 `lyric-data.js` 对应占位（搜索 `TODO: 填充歌词数据` 与 `TODO: 填充词性与活用`）。
3. **替换 hero 元信息**（HTML 里 5 处占位符）：`[歌名]`（含 `<title>`、`<h1>`、页脚）、`[歌手名]`、`[歌名中文译名]`、`[作词人]`、`[一句歌词主题/简介]`。务必全部替换，否则会残留上一首的标题信息。
4. **设计 hero 氛围（配色 + 特效）**：每首歌按歌词意象定制 hero，默认是"深夜→破晓微光 + 飘雪"。改 `lyric-page.css` 两处：① `.hero{}` 段的背景渐变（带 `hero 氛围：配色 + 特效` 注释）——冷/暖色调、渐变走向随歌定；② 头部动画特效段（`.snow`，类名、HTML 子元素、`@keyframes` 命名一起换，可选泡沫上升 / 飘雪 / 花瓣飘落 / 星光闪烁 / 光尘漂浮 / 水面涟漪）。两处必须与这首歌的情绪一致，不要沿用上一首。若改特效类名，同步改 HTML 里对应元素。
5. 用渲染工具自检（如 `html` skill 的 `scripts/shot.py`）确认无 JS 报错、桌面+移动端布局正常、hero 显示本首歌信息，再交付。
6. 用 `present_files` 交付同目录四件套。

## 四、质检要点

- 拉丁字母英文未进入 `ws` / `POS`，也未加振假名或英文词法讲解。
- `S` 里所有 `ws` 的词形，都必须在 `POS` 表中有键（缺失时该词浮层信息不全）。
- 四类词（动词/形容词/助动词/句型）必须给 `form` 和 `forms`；其它词只给 `pos` 即可。
- 纯平假名词读音留空；片假名词读音用平假名。
- 翻译要与原文逐句对应，语法说明面向日语学习者，用 `<code>` 标出关键句型。
